# 类人记忆与情感动力学AI人格系统（MemHuman）

**一句话简介**：让本地部署的AI拥有“选择性遗忘、情绪累积、认知扭曲”能力的轻量化人格引擎。

**当前状态**：概念设计冻结（v2.0），计划于2029年Q1启动开发。

**核心创新**：
- 三级分级记忆指针（零级原文 → 三级关键词），检索效率超过MemGPT。
- 意图解耦模块（法律/事实与情绪并行处理），避免混合检索污染。
- S-U混沌人格系统，模拟“被反复无常对待后的认知扭曲”。
